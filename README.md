# 🎂 Proyecto Freelance: Invitación Web Interactiva

Este repositorio contiene el desarrollo de una solución digital personalizada para un evento social, entregada como proyecto freelance. El objetivo fue crear una experiencia interactiva y funcional que sustituyera las invitaciones físicas tradicionales.

### 📋 Requerimientos del Cliente
- **Diseño Personalizado:** Interfaz moderna y animada alineada con la temática del evento.
- **Interactividad:** Inclusión de efectos visuales (tsParticles) y cuenta regresiva.
- **Gestión de Datos:** Sistema de confirmación de asistencia integrado con base de datos.
- **Accesibilidad:** Optimización total para dispositivos móviles (Responsive Design).

### 🛠️ Tecnologías Aplicadas
* **Frontend:** HTML5, CSS3 y JavaScript (ES6+).
* **Animaciones:** Librerías de partículas y transiciones CSS personalizadas.
* **Backend & Datos:** Integración con base de datos en tiempo real para el manejo de invitados.
* **Despliegue:** GitHub Pages para el alojamiento del sitio en producción.

### 🚀 Resultados del Proyecto
Se logró una plataforma ligera y eficiente que permitió al cliente centralizar la lista de invitados y mejorar la comunicación del evento, demostrando la viabilidad de soluciones web para la gestión de eventos sociales.
